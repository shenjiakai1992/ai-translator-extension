核心功能

翻译这件事，拆成三件顺手的小事

读外文资料最烦的三种场景：整页看不懂、某个词不认识、文章太长没时间看。 一个扩展全部解决。

1

全页面翻译

点一下，整页外文就地变成中文。不是套一层遮罩，而是真正替换原文， 排版、链接、图片位置都不动。

  • 逐段翻译并显示进度，长页面心里有数
  • 两种显示方式：仅译文，或「译文 + 原文对照」
  • 随时一键还原，原文一字不差地回来
  • 代码块、表单、占位符变量不会被误翻
  • 快捷键 Alt + Shift + T

划词翻译

遇到不认识的句子，选中就行。浮出一个小按钮，点一下弹出译文卡片， 可拖动、可复制，不打断阅读节奏。

  • 选中即出按钮，不打扰原本的阅读
  • 译文卡片可拖动、可复制、可随手关掉
  • 也可以在选中后直接右键翻译
  • 函数名、变量、网址、数字保持原样

安装说明

五分钟装好，从此告别复制粘贴

扩展未上架商店，用「加载已解压的扩展程序」方式安装，手动更新一次即可长期使用。

  1. 1

    获取源码

    把项目下载到本地任意目录（路径尽量别带特殊符号）。

    终端 
    git clone https://github.com/shenjiakai1992/ai-translator-extension.git
  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入下面这行并回车，然后打开页面右上角的「开发者模式」开关。

    地址栏 
    chrome://extensions/
  3. 3

    加载扩展

    点左上角「加载已解压的扩展程序」，选择项目里的 ai-translator-extension 文件夹——就是含 manifest.json 的那一层， 不要选成它的上级目录。

    装好后建议点浏览器工具栏的拼图图标，把「AI 翻译助手」固定出来。

  4. 4

    配置模型

    点扩展图标 → 展开设置，填三项：接口地址、API Key、模型名称。 先点「测试连接」确认能通，再点「保存设置」。

    这三项都来自你自己的模型服务账号，插件不代充、不转发。填错地址插件会自动纠正。

  5. 5

    开始使用

    打开任意外文网页：点「翻译本页」整页翻译，选中文字划线翻译， 点「总结本页」看要点。快捷键 Alt + Shift + T 可直接翻译整页。

注意要点

装之前先看这几条，能省不少事

下面都是实际使用中容易踩到的点，提前知道就不用到处找原因了。

⚑

必须自备 API Key

插件不内置任何密钥，也不提供代充或转发服务。你需要在自己的模型服务商后台申请一个 Key， 费用直接结算给你选的服务商，插件不参与。

!

Base URL 别填成密钥管理页

这是最常见的一个坑。以 DeepSeek 为例：

错误 https://platform.deepseek.com/api_keys（那是网页后台）
正确 https://api.deepseek.com/v1（这才是接口地址）

插件会识别并自动纠正这类误填，但自己填对更省事。

✕

这三类页面用不了

Chrome 不允许任何扩展在这些页面注入脚本，不是插件的问题：

浏览器内置页面（chrome:// 开头）、Chrome 应用商店、PDF 阅读器。
换成普通网页即可，弹窗里也会给出提示。

↻

刚装好时，已打开的网页要刷一下

这是 Chrome 的行为：安装扩展之前就已经打开的页面不会自动注入脚本。

现在插件会自动补注入，一般无需处理；如果仍提示页面不可用， 点弹窗里的「重试」或按 F5 刷新即可。

✽

密钥与记录都只存在本机

API Key、翻译历史、用量统计全部保存在你自己的浏览器里，不同步、不上传。 请求由插件后台直接发往你填的服务地址，不经过任何中间服务器。

管理面板里可以关闭「记录历史」，也可以只留元信息、不保存原文译文。

◑

token 消耗与费用

整页翻译会产生真实调用费用，长页面尤其明显。建议保持「快速模式」开启 （关闭模型思考链，实测响应更快、token 更省）。

想心里有数，可以在管理面板的「用量统计」里看每天花了多少，填上单价还能估算费用。

◎

浏览器版本要求

需要 Chrome 110 及以上（基于 Manifest V3）。Edge 等 Chromium 内核浏览器同样可用。

⌘

给开发者的提示

Chrome 137 起，品牌版 Chrome 移除了 --load-extension 命令行参数， 因此扩展的自动化测试需要用 Chrome for Testing 或 Chromium 加载。

日常使用不受影响，手动加载照样可用。

常见问题

你可能还想问

点插件图标提示「这个页面用不了扩展」怎么办？
先确认不是浏览器内置页面（chrome:// 开头）、Chrome 应用商店或 PDF 阅读器—— 这三类页面 Chrome 不允许注入脚本。如果确认是普通网页， 点弹窗里的「重试」，或按 F5 刷新一次即可。
提示 API Key 无效或认证失败？
九成是 Base URL 填错了。它不是网页后台地址，而是接口地址，多数服务商需要带 /v1，例如 https://api.deepseek.com/v1。 其次检查 Key 是否复制完整（首尾别带空格）、账号余额是否充足。 填好后先点「测试连接」，通过再保存。
翻译会改动我原来的网页吗？能还原吗？
只在当前这次浏览里替换文本，不会修改服务器上的任何内容。 点提示条上的「还原」或弹窗里的「还原原文」，页面会逐字恢复到你翻译前的样子， 包括双语对照模式下插入的原文块也会一并清理。
长页面翻译很慢，怎么办？
三点建议：一、保持「快速模式」开启，它会关闭模型的思考链；二、先把目标语言设对， 避免每次都要看图判断；三、如果只是想了解内容大意，用「总结本页」比整页翻译省得多。 翻译过程中右下角会显示进度，随时可以点「停止」。
我的 API Key 安全吗？
Key 只保存在你本机的浏览器存储里，且只由插件后台使用，网页脚本拿不到它。 插件代码完全公开，可以自行审计。 唯一的建议：不要在公共电脑上使用，也别把 Key 分享给别人。
为什么翻译结果里有些词没变？
这是有意为之。代码块、变量名、函数名、网址、邮箱、百分比占位符（如 %s、{0}）如果被翻译，反而会让代码或模板失效， 所以插件要求模型原样保留，并且自动跳过 <script>、<code>、<pre> 等标签里的内容。
换电脑或重装浏览器后需要重装吗？
需要。因为扩展是本地加载的，配置不会自动同步。 重新加载一次扩展后，把 Base URL、API Key、模型名再填一遍即可。 历史记录和用量统计属于本地数据，也不会跟着走。
