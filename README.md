# AI 翻译助手 · Chrome 浏览器插件

一个基于**任意 OpenAI 兼容协议大模型**的浏览器翻译插件，包含三大功能：

| 功能 | 说明 |
| --- | --- |
| 🌐 **全页面翻译** | 一键把整页英文换成中文（或反向），支持「仅译文」和「译文 + 原文对照」两种显示方式，随时一键还原 |
| ✂️ **划词翻译** | 选中任意文字，浮出「译」按钮，点一下弹出译文卡片，可复制、可拖动 |
| 📄 **网页总结** | 自动抓取正文，让模型提炼要点，右侧边栏展示结构化总结 |
| 📊 **管理面板** | 独立页面：模型配置、源/目标语言切换、**翻译历史记录**、**token 用量统计**（按天/模型/类型 + 费用估算） |
| 🔧 **老页面自动补注入** | 扩展刚安装时，之前已经打开的网页不会自动注入脚本——插件会检测到并**自动补注入一次**，不需要手动刷新 |

- 不绑定任何一家模型服务：**Base URL、API Key、模型名全部由用户自己填写**，兼容 OpenAI / DeepSeek / 通义千问 / 智谱 / Kimi 等所有 OpenAI 协议接口
- API Key 只保存在本机浏览器（`chrome.storage.local`），不会上传到任何第三方
- 界面简洁，支持深色模式，中英互译及 8 种常用语言

## 一、安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」，选择本文件夹（`ai-translator-extension`）
4. 浏览器工具栏出现蓝色「译」图标即安装成功（建议点击拼图图标把它固定到工具栏）

> Chrome 137 之后官方收紧了命令行加载扩展，但**通过 `chrome://extensions` 手动加载不受影响**。

## 三、使用说明

### 1. 翻译整个页面

- 点扩展图标 → 「**翻译本页**」
- 或按快捷键 `Alt + Shift + T`（可在 `chrome://extensions/shortcuts` 改）
- 或在页面空白处右键 → 「AI 翻译整个页面」

翻译过程中右下角会显示进度（`翻译中 45% · 已翻译 120/266 段`），结束后显示耗时和替换处数。
点提示条上的「**还原**」可随时切回原文；弹窗里的「还原原文」是同一个功能。
翻译完成后扩展图标上会出现「译」角标。

### 2. 划词翻译

选中任意文字 → 页面浮出「**译**」按钮 → 点击 → 弹出译文卡片。
卡片支持拖动、复制译文、关闭。也可以在选中文字后**右键** → 「AI 翻译："xxx"」。

### 3. 网页总结

点扩展图标 → 「**总结本页**」→ 右侧滑出总结面板，输出「一句话结论 + 要点列表 + 适合谁看」。

### 4. 管理面板

点插件弹窗底部的「**打开管理面板**」，或在 `chrome://extensions` 里点「扩展程序选项」。
面板是独立标签页（宽屏布局），五个分区：

| 分区 | 内容 |
| --- | --- |
| **概览** | 累计请求 / token / 今日用量 / 翻译字数四张卡；模型接入状态（Key 脱敏显示）；最近 5 条翻译；一键测试连接 |
| **模型配置** | Base URL（实时校验 + 误填纠正）、API Key（可显示/隐藏）、模型名称（带常用模型候选）、测试连接、保存；另附常见服务商地址对照表 |
| **语言与翻译** | 源语言（含「自动检测」）+ 目标语言，中间有 **⇄ 互换按钮**；译文显示方式、快速模式、划词/自动翻译开关 |
| **历史记录** | 每次翻译/总结一行：类型标签、内容预览、token、语言方向、时间；可展开看原文与译文并复制；支持按类型筛选、关键词搜索、单条删除、一键清空 |
| **用量统计** | 累计 token（输入/输出分开）、近 7 天、估算费用；**近 14 天柱状图**；按模型 / 按操作类型分布；可填单价做费用估算；可清空统计 |

**关于隐私与存储**

- 历史与统计都只存在本机（`chrome.storage.local`），不会同步、不会上传
- 面板里可以**关闭「记录历史」**（关闭后不再新增，已有记录保留）
- 也可以**关闭「保存正文」**，只留类型/语言/token/耗时等元信息，不保存原文与译文
- 默认最多保留 300 条（可调 100~1000），正文预览单条最多 500 字，超出自动截断
- 「清空历史」只清记录、保留累计用量；「清空统计」会连历史一起清（否则历史还在、统计归零会很怪）
- 估算费用需要你自己填单价——插件不内置价格表，避免价格变动后误导

## 五、常见问题

**Q：刚安装完，点插件图标提示「这个页面用不了扩展」？**
A：扩展刚安装或重载时，**之前已经打开的网页不会自动注入内容脚本**（这是 Chrome 的行为）。
插件在 v1.0.1 起会自动补注入一次，通常无需处理；如果仍提示，点提示里的「重试」，或直接刷新页面（F5）。
真正不支持的是：浏览器内置页面（`chrome://`）、Chrome 应用商店、PDF 阅读器。

**Q：翻译没反应 / 报「API Key 无效」？**
A：进设置点「测试连接」。最常见的两个原因是 Key 填错、Base URL 填成了密钥管理页而不是接口地址
（正确写法如 `https://api.deepseek.com/v1`）。

**Q：长页面翻译很慢或很费 token？**
A：保持「快速模式」开启（默认开），可关闭模型思考链；页面里重复出现的文案会自动去重只翻一次。

**Q：改了显示方式要重新翻译吗？**
A：设置改动即时生效，重开弹窗重新点一次「翻译本页」即可，不需要重启浏览器。

## 八、实现要点

1. **API Key 不下发到页面**：所有模型请求都在后台 Service Worker 发出，内容脚本只能发文本、拿译文。
2. **Shadow DOM 隔离 UI**：页面上的所有界面（划词按钮、译文卡片、进度条、总结面板）都挂在 Shadow DOM 里，
   网页样式污染不了它，它也不影响网页。
3. **老页面自动补注入**：扩展安装/重载前就打开的标签页不会自动注入内容脚本（Chrome 的行为），
   插件会先 `PING` 探活，失败则用 `chrome.scripting.executeScript` 补注入一次再重试，
   用户不需要自己刷新页面；真正的内置页面（`chrome://`）等会返回失败原因并提示。
4. **批量翻译 + 拆批自愈**：整页文本按 20 条一批、3 批并发送给模型；一旦模型返回条数不匹配或格式错误，
   自动二分拆小重试，直到单条；单条仍失败就保留原文并记录，不阻塞整页。
5. **重复文案去重**：页面里重复出现的文案（导航、按钮）只翻译一次，省 token。
6. **关闭思考链**：请求时带 `thinking:{"type":"disabled"}`，实测响应从 4.4s 降到 1.3s、推理 token 归零；
   接口不支持该参数时自动去掉参数重试，并把能力缓存下来。
7. **错误归一化**：401 / 403 / 404 / 429 / 5xx / 超时 / 网络错误全部映射成中文可读提示；
   401、403、404 判定为致命错误不重试，429 和 5xx 指数退避重试。
8. **跳过不该翻的内容**：`<script>` `<style>` `<code>` `<pre>` `<textarea>` 等标签内的文本、
   可编辑区域、占位符变量（`%s`、`{0}`、`$VAR`）、网址、纯数字都不会被翻译。

> 权限说明：`storage`（存配置）、`contextMenus`（右键菜单）、`scripting`（给老标签页补注入内容脚本）、
> `host_permissions: <all_urls>`（让用户能填任意模型服务地址，并允许注入任意网页）。

## 九、已知限制

- 浏览器内置页面（`chrome://`）、Chrome 应用商店、PDF 阅读器里无法注入脚本，这些页面用不了，弹窗里会给出提示。
- 翻译长页面会产生较多 token 消耗，建议先在小页面试跑，或把「快速模式」保持开启。
- 动态加载内容的网站（无限滚动、单页应用切换路由）需要重新点一次翻译。
- 表格、`<canvas>` 绘制的文字、图片里的文字无法翻译。
