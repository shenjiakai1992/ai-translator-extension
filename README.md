# AI 翻译助手 · Chrome 浏览器插件

一个基于**任意 OpenAI 兼容协议大模型**的浏览器翻译插件，包含三大功能：

| 功能 | 说明 |
| --- | --- |
| 🌐 **全页面翻译** | 一键把整页英文换成中文（或反向），支持「仅译文」和「译文 + 原文对照」两种显示方式，随时一键还原 |
| ✂️ **划词翻译** | 选中任意文字，浮出「译」按钮，点一下弹出译文卡片，可复制、可拖动 |
| 📄 **网页总结** | 自动抓取正文，让模型提炼要点，右侧边栏展示结构化总结 |

- 不绑定任何一家模型服务：**Base URL、API Key、模型名全部由用户自己填写**，兼容 OpenAI / DeepSeek / 通义千问 / 智谱 / Kimi 等所有 OpenAI 协议接口
- API Key 只保存在本机浏览器（`chrome.storage.local`），不会上传到任何第三方
- 界面简洁，支持深色模式，中英互译及 8 种常用语言

---

## 一、安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」，选择本文件夹（`ai-translator-extension`）
4. 浏览器工具栏出现蓝色「译」图标即安装成功（建议点击拼图图标把它固定到工具栏）

> Chrome 137 之后官方收紧了命令行加载扩展，但**通过 `chrome://extensions` 手动加载不受影响**。

## 二、配置模型

点击工具栏的扩展图标 → 点右上角 ⚙ 展开设置，填三项：

| 配置项 | 示例 | 说明 |
| --- | --- | --- |
| 接口地址 Base URL | `https://api.deepseek.com/v1` | 注意：**不是**密钥管理页地址 |
| API Key | `sk-xxxxxxxx` | 在模型服务商后台申请 |
| 模型 | `deepseek-flash` | 也可填 `deepseek-chat`、`gpt-4o-mini`、`qwen-plus` 等 |

填完先点「**测试连接**」确认能通，再点「**保存设置**」。

## 三、使用说明

### 1. 翻译整个页面

- 点扩展图标 → 「**翻译本页**」
- 或按快捷键 `Alt + Shift + T`（可在 `chrome://extensions/shortcuts` 改）
- 或在页面空白处右键 → 「AI 翻译整个页面」

翻译过程中右下角会显示进度（`翻译中 45% · 已翻译 120/266 段`），结束后显示耗时和替换处数。
点提示条上的「**还原**」可随时切回原文；弹窗里的「还原原文」是同一个功能。
翻译完成后扩展图标上会出现「译」角标。

### 2. 划词翻译

选中任意文字 → 页面浮出「**译**」按钮 → 点击 → 弹出译文卡片。
卡片支持拖动、复制译文、关闭。也可以在选中文字后**右键** → 「AI 翻译："xxx"」。

### 3. 网页总结

点扩展图标 → 「**总结本页**」→ 右侧滑出总结面板，输出「一句话结论 + 要点列表 + 适合谁看」。

### 其他设置

| 设置 | 说明 |
| --- | --- |
| 目标语言 | 简体中文 / 繁体中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语 / 葡萄牙语 |
| 显示方式 | **仅显示译文**（原地替换）/ **译文 + 原文对照**（译文后面用小灰字附上原文） |
| 快速模式 | 关闭模型思考链，翻译明显更快更省 token（接口不支持时会自动降级重试） |
| 划词翻译 | 是否开启选中文字浮按钮 |
| 自动翻译 | 打开网页后自动翻译整页（默认关闭） |

> 设置里切换语言、显示方式、开关会**即时生效**，不需要重开页面。

## 六、实现要点

1. **API Key 不下发到页面**：所有模型请求都在后台 Service Worker 发出，内容脚本只能发文本、拿译文。
2. **Shadow DOM 隔离 UI**：页面上的所有界面（划词按钮、译文卡片、进度条、总结面板）都挂在 Shadow DOM 里，
   网页样式污染不了它，它也不影响网页。
3. **批量翻译 + 拆批自愈**：整页文本按 20 条一批、3 批并发送给模型；一旦模型返回条数不匹配或格式错误，
   自动二分拆小重试，直到单条；单条仍失败就保留原文并记录，不阻塞整页。
4. **重复文案去重**：页面里重复出现的文案（导航、按钮）只翻译一次，省 token。
5. **关闭思考链**：请求时带 `thinking:{"type":"disabled"}`，实测响应从 4.4s 降到 1.3s、推理 token 归零；
   接口不支持该参数时自动去掉参数重试，并把能力缓存下来。
6. **错误归一化**：401 / 403 / 404 / 429 / 5xx / 超时 / 网络错误全部映射成中文可读提示；
   401、403、404 判定为致命错误不重试，429 和 5xx 指数退避重试。
7. **跳过不该翻的内容**：`<script>` `<style>` `<code>` `<pre>` `<textarea>` 等标签内的文本、
   可编辑区域、占位符变量（`%s`、`{0}`、`$VAR`）、网址、纯数字都不会被翻译。

## 七、已知限制

- 浏览器内置页面（`chrome://`）、Chrome 应用商店、PDF 阅读器里无法注入脚本，这些页面用不了，弹窗里会给出提示。
- 翻译长页面会产生较多 token 消耗，建议先在小页面试跑，或把「快速模式」保持开启。
- 动态加载内容的网站（无限滚动、单页应用切换路由）需要重新点一次翻译。
- 表格、`<canvas>` 绘制的文字、图片里的文字无法翻译。
